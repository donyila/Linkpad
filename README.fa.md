# LinkPad

یک وب‌اپلیکیشن سبک برای رد و بدل کردن متن کلیپ‌بورد و فایل بین دو (یا چند) دستگاه در یک شبکه محلی.

## نصب و اجرا (روی لینوکس)

```bash
cd lansync
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python3 app.py
```

پس از اجرا، در ترمینال دو آدرس نمایش داده می‌شود:

```
On this computer :  http://127.0.0.1:5000
On other devices  :  http://192.168.x.x:5000
```

- در همان کامپیوتر، آدرس `127.0.0.1:5000` را باز کنید.
- در دستگاه دیگر (موبایل، لپ‌تاپ دیگر و ...) که به همان Wi‑Fi/شبکه محلی متصل است، آدرس دوم (مثل `http://192.168.x.x:5000`) را در مرورگر باز کنید.

هر متنی که در کادر «کلیپ‌بورد مشترک» نوشته شود، به‌صورت خودکار (هر ۲ ثانیه) روی همه دستگاه‌های باز شده به‌روزرسانی می‌شود. فایل‌ها هم با درگ-اند-دراپ یا کلیک روی ناحیهٔ آپلود، روی سرور (همان کامپیوتر لینوکسی) ذخیره می‌شوند و از هر دستگاه دیگری قابل دانلود هستند.

## نکات

- پورت پیش‌فرض `5000` است؛ برای تغییر آن: `PORT=8080 python3 app.py`
- فایل‌ها در پوشهٔ `uploads/` کنار برنامه ذخیره می‌شوند.
- اگر فایروال سیستم لینوکسی فعال است، ممکن است لازم باشد پورت را باز کنید، مثلاً:
  `sudo ufw allow 5000/tcp`
- دکمه‌های «جای‌گذاری از کلیپ‌بورد» و «کپی به کلیپ‌بورد» روی خودِ کامپیوتر سرور (آدرس 127.0.0.1) به‌خوبی کار می‌کنند. در دستگاه‌های دیگر که از طریق IP (نه https) وصل می‌شوند، مرورگرها معمولاً دسترسی مستقیم برنامه به کلیپ‌بورد سیستم را برای آدرس‌های HTTP غیر-localhost محدود می‌کنند؛ در آن حالت کافیست متن را داخل کادر انتخاب و با Ctrl+C / Ctrl+V به‌صورت دستی کپی/جای‌گذاری کنید — خودِ متن همچنان بین دستگاه‌ها به‌صورت زنده همگام می‌شود.
- برای اجرای همیشگی در پس‌زمینه می‌توانید از `tmux`، `screen` یا یک سرویس systemd استفاده کنید.

