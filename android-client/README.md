# LinkPad Android Client — ساخت رایگان APK با GitHub Actions

این پوشه یک اپ اندرویدی سبک (Kotlin، بر پایهٔ WebView) است که رابط کاربری سرور LinkPad شما را داخل یک اپ واقعی نصب‌شدنی روی گوشی نمایش می‌دهد. به‌جای نیاز به Android Studio یا هر سرویس پولی، ساخت APK با **GitHub Actions** (کاملاً رایگان برای مخازن عمومی/خصوصی در حد معمول) انجام می‌شود.

## چطور کار می‌کند؟

هر بار که تغییری در پوشهٔ `android-client/` به شاخهٔ `main` پوش کنید، فایل `.github/workflows/build-apk.yml` به‌صورت خودکار روی سرورهای گیت‌هاب اجرا می‌شود، پروژه را کامپایل می‌کند، و یک فایل APK آماده به‌عنوان **Artifact** تحویل می‌دهد — بدون اینکه چیزی روی کامپیوتر خودتان نصب یا اجرا شود.

## مراحل

۱. مطمئن شوید این پوشه (`android-client/`) و پوشهٔ `.github/workflows/` را در مخزن گیت‌هاب `push` کرده‌اید:

```bash
git add .
git commit -m "Add Android client + APK build workflow"
git push
```

۲. در مرورگر به صفحهٔ مخزن خودتان بروید و تب **Actions** را باز کنید.

۳. باید یک اجرای جدید به اسم «Build Android APK» ببینید که در حال اجراست (دایرهٔ زرد در حال چرخش). چند دقیقه صبر کنید تا تیک سبز بخورد.

۴. روی همان اجرا کلیک کنید؛ در پایین صفحه بخش **Artifacts** را ببینید — یک فایل به اسم `LinkPad-debug-apk` آنجا قابل دانلود است.

۵. آن را روی گوشی اندرویدی دانلود کنید. چون از منبع ناشناخته (خارج از Google Play) است، اندروید یک هشدار نشان می‌دهد — باید اجازهٔ نصب از «منابع ناشناس» را برای مرورگر یا فایل‌منیجرتان فعال کنید (Settings → Apps → دسترسی ویژه → Install unknown apps).

## اولین اجرا روی گوشی

با باز کردن اپ، یک پنجره برای وارد کردن آدرس سرور (همان `http://192.168.x.x:5000` که سرور چاپ می‌کند) باز می‌شود. بعد از وارد کردن و زدن «اتصال»، اپ همیشه همان آدرس را به خاطر می‌سپارد. برای تغییر بعدی: از منوی سه‌نقطهٔ بالای صفحه → «تنظیم آدرس سرور».

## محدودیت‌های نسخهٔ رایگان GitHub Actions

- مخازن عمومی (Public): دقایق اجرا کاملاً رایگان و نامحدود است.
- مخازن خصوصی (Private): حساب رایگان گیت‌هاب ماهانه ۲۰۰۰ دقیقه رایگان می‌دهد — این پروژهٔ کوچک هر بار حدود ۳ تا ۵ دقیقه طول می‌کشد، پس برای توسعهٔ شخصی کاملاً کافی است.

## ساختار پروژه

```
android-client/
  build.gradle              # تنظیمات کلی Gradle
  settings.gradle
  gradle.properties
  app/
    build.gradle             # تنظیمات ماژول اپ (نام پکیج، نسخهٔ SDK)
    src/main/
      AndroidManifest.xml
      java/com/linkpad/client/MainActivity.kt   # منطق WebView + ذخیرهٔ آدرس سرور
      res/values/strings.xml
      res/drawable/ic_launcher.xml
```

## توسعهٔ بعدی

اگر بعداً به یک کامپیوتر قوی‌تر یا Android Studio دسترسی پیدا کردید، همین پوشه را مستقیم با **File → Open** در Android Studio باز کنید — پروژه استاندارد Gradle است و بدون تغییر خاصی قابل توسعه به یک اپ نیتیو کامل‌تر (خواندن مستقیم کلیپ‌بورد سیستم، دکمهٔ Share و ...) خواهد بود.
